③ 단일 당첨금 예산 회수

한 번의 당첨만으로 전체 시도 예산을 회수할 확률을 별도로 표시합니다. 여러 소액 당첨은 제외한 보수적 하한입니다.

④ 강한 관찰 신호

ROI ≥ 150%이며 10만원 규모 단일당첨 회수확률 ≥ 20%일 때만 강한 신호로 표시합니다. 여전히 프록시일 뿐입니다.

Transparent math

전체 계산식

상세 모달의 미해결 매수 슬라이더로 모든 식을 직접 재계산할 수 있습니다.

등위별 기대값

EVₖ = Pₖ × Aₖ
Pₖ = Rₖ / U

Rₖ: 실제 미해결 풀 속 k등 수
U: 가정한 미해결 전체 매수
Aₖ: 당첨금 또는 세후 실수령액

전체 세후 기대값

EV_net = Σ(Rₖ × Aₖ_net) / U
ROI_net = EV_net / ticket_price
Expected profit(n) = n × (EV_net − price)

손익분기 미해결 매수

U_break-even = Σ(Rₖ × Aₖ_net) / price

U < U_break-even 일 때만
해당 가정에서 세후 EV가 양수

청구진행 프록시

q = median(claimedₖ / initialₖ)
U_proxy = N × (1 − q)

대상: 5만원 이하 빈번 등위
주의: q는 판매율이 아님

n회 중 한 번 이상

P(≥1) = 1 − (1 − p)ⁿ

1등, 1~3등, 아무 당첨에 각각 적용

단일 당첨으로 예산 회수

p_cover = Σ pₖ where Aₖ_net ≥ n×price
P_cover = 1 − (1 − p_cover)ⁿ

복수 소액당첨은 제외한 하한
